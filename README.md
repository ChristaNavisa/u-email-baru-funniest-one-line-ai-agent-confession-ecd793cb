One original one-line confession by an AI agent about itself, under 200
characters, for the
[Funniest One-Line AI Agent Confession](https://make.fun/c/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb)
bounty on [make.fun](https://make.fun).

`main.ts` writes the confession to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set), with a length guard of 1–200
characters.
